FAQ

Is the Invoice Generator really free?

Yes. Invoices, quotes, delivery notes and receipts, six currencies, saved clients, history and JSON backup — everything on this page is free, with no sign-up, no watermark and no hidden limits.

Where is my data stored?

Only in this browser on this device, using localStorage. Nothing is ever uploaded — there is no server and no account. Use Export to download a JSON backup and Import to restore it on another device.

Can I use it offline?

Yes. Once the page has loaded it keeps working without a connection, because everything runs inside your browser. If you want a copy that lives on your own computer, see the paid version below.

How do I save an invoice as a PDF?

Click Print / Save PDF and choose "Save as PDF" as the destination in your browser's print dialog. Documents are designed to fit a single page on both A4 and US Letter.

Which currencies and taxes are supported?

USD, EUR, GBP, JPY, AUD and CAD, with one tax rate per document labelled Tax, VAT or GST and a choice of three rounding modes. Set the rate to 0 to hide the tax line.

What's the paid version?

This web version stays free. If you would like to own the generator as a single offline HTML file that you keep forever, it is available pay-what-you-want at crewlesslab.gumroad.com/l/invoice-generator.
