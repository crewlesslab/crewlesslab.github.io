FAQ

Is the Resume Builder really free?

Yes. Both templates, unlimited saved versions, JSON backup and PDF printing — everything on this page is free, with no sign-up, no watermark and no hidden limits.

Where is my resume data stored?

Only in this browser on this device, using localStorage. Nothing is ever uploaded — there is no server and no account. Use Export to download a JSON backup and Import to restore it on another device.

Can I use it offline?

Yes. Once the page has loaded it keeps working without a connection, because everything runs inside your browser. If you want a copy that lives on your own computer, see the paid version below.

Is the resume ATS-friendly?

Yes. Both templates render as a plain top-to-bottom text flow without tables or graphics, and the Compact template prints as a single linear column, so applicant tracking systems can parse the exported PDF cleanly.

How do I save my resume as a PDF?

Click Print / Save PDF and choose "Save as PDF" as the destination in your browser's print dialog. The resume fits A4 and US Letter in one to two pages.

What's the paid version?

This web version stays free. If you would like to own the builder as an offline HTML file that you keep forever, it is available pay-what-you-want at crewlesslab.gumroad.com.
